# Neon Rain

> 雨下了十一年。旧城·第九街区的巡逻无人机今晚全部失控——清掉五波，从霓虹里活着走出去。

**Neon Rain** 是一款基于浏览器的第一人称波次射击游戏。玩家被困在雨夜街区中，使用单把 MK-7 步枪迎战五波失控无人机，并依靠掩体、机动和精准射击生存下来。

游戏采用原生 JavaScript 与 Three.js 实现，场景、贴图、粒子和音效均在运行时程序化生成。最终产物是一个无需服务器、无需网络请求、可直接打开的单文件 HTML。

---

## 玩法特点

- **五波无人机清场**：从 3 架逐步增加到 7 架，第 3 波开始出现更耐打的 Gunner。
- **两种敌人**：机动灵活的 Scout 与火力更强、装甲更厚的 Gunner。
- **第一人称战斗**：移动射击、机瞄、后坐力、移动散布、换弹与动态准星。
- **生存机制**：100 HP，脱离受伤 5.2 秒后开始恢复生命。
- **得分结算**：根据击杀类型计分，并在结算界面展示击杀、爆头和命中率。
- **雨夜霓虹氛围**：程序化街区、湿地镜面反射、体积感低雾、雨线、飞溅和霓虹辉光。
- **程序化音频**：枪声、脚步、命中、爆炸、雷声和环境氛围均由 Web Audio 实时合成。
- **画质档位**：支持自动、极致、高、中、低五档设置。

## 操作方式

| 操作 | 键位 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 视角 | 移动鼠标 |
| 疾跑 | `Shift + W` |
| 跳跃 | `Space` |
| 下蹲 | `Left Ctrl` 或 `C` |
| 射击 | 鼠标左键，按住可连续射击 |
| 机瞄 | 鼠标右键 |
| 换弹 | `R` |
| 战术手电 | `F` |

开始游戏或点击“继续行动”时，浏览器会请求锁定鼠标指针。若指针锁定失败，游戏会自动暂停。建议在独立浏览器窗口中打开，而不是嵌入预览容器。

## 游戏规则

- 共 **5 波**，每波敌人数量为 `2 + 波数`，即 3、4、5、6、7 架。
- **Scout**：90 HP，移动速度较快，发射 10 点伤害的能量弹。
- **Gunner**：150 HP，移动较慢，发射 15 点伤害的能量弹。
- 步枪身体伤害为 34，头部伤害为 100；Scout 可被一发爆头击杀。
- Scout 击杀得 120 分，Gunner 击杀得 220 分。
- 清空全部五波即可通关；生命值归零则任务失败。
- 备弹无限，单局得分与统计数据不会持久化保存。

## 运行

### 直接游玩

1. 使用现代桌面浏览器打开项目根目录下的 `霓虹雨夜_NEON_RAIN.html`。
2. 点击“进入街区”。
3. 建议全屏并佩戴耳机。

该文件已经内联 Three.js、游戏代码、样式和 UI，无需 `npm install`，也无需启动本地服务器。

> 不要直接打开 `src/index.html`。它只是构建模板，脚本位置仍为占位符。

### 重新构建

修改 `src/` 中的源码后，在项目根目录运行：

```powershell
node build.js
```

构建脚本会：

1. 按指定顺序合并 `src/*.js`；
2. 生成用于检查的 `build/game.bundle.js`；
3. 将 Three.js 与游戏代码内联到 `霓虹雨夜_NEON_RAIN.html`。

构建只需要 Node.js，不需要安装任何第三方依赖。

## 技术栈

- 原生 HTML、CSS 和 JavaScript
- Three.js r160（本地 UMD 版本）
- WebGL 渲染与自定义后处理管线
- 平面反射、HDR 渲染目标、多级 Bloom、ACES 色调映射
- Web Audio API 程序化音频
- 无 npm 包、无 CDN、无外部图片或音频素材

---

## 注意事项

- 游戏面向桌面键鼠设计，依赖 Pointer Lock，不支持触摸或手柄操作。
- 当前游戏界面为中文。
- 平面反射与多级 Bloom 对显卡有一定要求；低端设备可在开始界面降低画质档位，或使用自动适配。
- Three.js r160 的 UMD 构建会在浏览器控制台输出弃用警告，但不影响游戏运行。
- 没有存档、排行榜或武器切换系统；单局内容集中在五波快节奏清场。
